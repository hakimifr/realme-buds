## Why GPL

The device profiles under `realmebuds/profiles/builtin/` (everything except
`realme-buds-air7-pro.json`) are generated by `scripts/import_quickbuds.py` from the model data in
**QuickBuds** (<https://github.com/spizganed/QuickBuds>, copyright (C) 2026 spizganed, GPL-3.0-or-later),
`app/src/main/assets/models.json`. QuickBuds extracted that data from HeyMelody and realme Link. The profiles
are a derived work of it, and so this repository is distributed under the same license. If you only want the
code without the generated profiles, delete those files and the importer. The built-in Air7 Pro profile was
written for this project from its own research, but the protocol knowledge it builds on comes from the sources
below.
